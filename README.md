# Movie App

## Description

A simple full-stack web application that displays a list of movies and their details.

## Technologies Used

* Node.js
* Express.js
* HTML
* CSS
* JavaScript

## Features

* View movie list
* View movie details
* REST API backend
* Responsive user interface

## Project Structure

movie-app/

* server.js
* package.json
* data/

  * movies.js
* public/

  * index.html
  * style.css
  * script.js
  * images/

## How to Run

1. Install dependencies

npm install

2. Start the server

node server.js

3. Open in browser

http://localhost:3000
